# Security

Report suspected vulnerabilities in this fork privately through
[GitHub vulnerability reporting](https://github.com/otpki/iogo/security/advisories/new).
Do not disclose them in public issues or pull requests. Include the affected
commit or version, a minimal reproduction using synthetic inputs, and the impact.

If the issue also affects unmodified Go, follow
[Go's security policy](https://go.dev/security/policy) to coordinate disclosure
with upstream. For issues in CIRCL, also consult
[the fork's security policy](https://github.com/otpki/circl/security/policy).

Fixes to the standalone library target `main`. This fork does not establish
a separate security support commitment for older Go or IOGO releases.
